# Security policy

This repository is an experimental research prototype. It has not been audited,
certified under NIST SP 800-90B, or shown suitable for cryptographic use.

Do not use generated output for keys, passwords, authentication tokens,
lotteries, financial decisions or systems where safety is critical.

If you find a flaw in the collection, extraction or analysis code, open a
GitHub issue without including private credentials or sensitive data. A result
that weakens the randomness claims is useful evidence and will not be treated
as an embarrassment to hide.
