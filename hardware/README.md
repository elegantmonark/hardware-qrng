# Hardware evidence

Hardware records are separated by experimental demonstrator:

- **ED-1:** original working breadboard demonstrator and April 2026 acquisition setup.
- **ED-2:** improved breadboard circuit documented in `../circuit.md`.
- **ED 3:** simplified buffered reference circuit, validated on breadboard first,
  with optional perfboard transfer and repeat checks afterwards. Assembly and
  validation remain pending.
- **ED 4:** custom PCB for the printed enclosure, with a nominal 89 by 52 mm
  outline. The ED4 A Arduino layout is available for review. The enclosure
  base and bare board fit check exist; electrical validation and populated
  fit remain pending. ED4 E for ESP32 is planned separately.

Each photograph should have a descriptive filename and a nearby caption recording what it shows, when it was taken, and whether the pictured configuration produced a published dataset. Images should be checked for location metadata, personal information, labels, and unrelated background material before publication.
