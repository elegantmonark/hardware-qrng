# Firmware

Firmware is stored by experimental demonstrator so that an old dataset is not accidentally attributed to a newer circuit or sampler.

- `ED-1/qrng_sampler_ed1.ino` is the archived sampler associated with the original demonstrator and April 2026 data.
- `ED-2/entropy_sampler_ed2.ino` is preserved with the two-stage breadboard development circuit.
- `ED-3/entropy_sampler_ed3.ino` is the current bring-up sampler for the simplified breadboard.

Firmware version, circuit version, baud rate, nominal sampling interval, and any local changes must be recorded with each dataset.
